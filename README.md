# Hopping - Animated Landing Page 🏝️

A landing page for **Hopping**, a social app helping newcomers meet friends through shared hobbies (coffee, treks, cricket, badminton, food walks, music jams, and casual hangs).

## 🚀 Tech Stack
- **Framework**: Next.js 16 (App Router) + TypeScript
- **Styling**: Tailwind CSS v4 with curated design tokens
- **Animations**: Framer Motion (floating physics, parallax, SVG pathLength drawing, reduced-motion support)
- **Typography**: Google Fonts (`Caveat Brush` for display headers & paper cards, `Plus Jakarta Sans` for UI)
- **Assets**: Transparent illustrated PNGs with Next.js Image optimization

---

## 🛠️ Quick Start

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
# Verify build
npm run build

# Run production server
npm run start
```

---

## 🚢 Deploy to Vercel
